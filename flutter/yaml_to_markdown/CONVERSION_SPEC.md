## YAML to Markdown 转换规范

将 YAML 转换为 Markdown 时，采用标题层级映射方式，具体规则如下：

### 层级结构
- YAML 的嵌套层级用 Markdown 标题符号（#）表示
- 顶层 key 为 `#`，每深一层增加一个 `#`
- key 本身作为标题文本，不加粗、不加引号
- 空值或纯结构性 key：保留标题

### 值的处理
- 简单值（字符串、数字等）：置于标题下一行，作为普通段落
- 数组：保留 Markdown 无序列表格式（`-` bullet）

## 示例

**YAML 输入**
```yaml
# 文件开头注释
world: 魔法世界

characters:
  Bob:
    class: 法师 # 行内注释
    # 独立行注释
    core:
      乐观: 永远开心
    skills:
      - 火球术
      - 冰冻术
```

**Markdown 输出**
```markdown
*文件开头注释*

# world
魔法世界

# characters
## Bob
### class
*行内注释*
法师

### core
*独立行注释*

#### 乐观
永远开心

### skills
- 火球术
- 冰冻术
```

## 未来支持
多行字符串
数组里嵌套对象
注释
### 注释的处理
- YAML 注释（`#` 开头，无论行内还是独立行）转为*斜体文本*
- 斜体注释置于对应标题的下一行，作为独立段落
- 若YAML文件开头注释对应整个文件或顶层，置于文档开头
